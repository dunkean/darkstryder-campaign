The Rules of Ron

| <br>[Image distante non téléchargée : http://users.vnet.net:80/seawolf/ron/images/ron27c.jpg]<br> | **The Rules of Ron<br><br>**Rules to go by in his RPGs games |
| --- | --- |

---

|  | 1) Everything explodes. Everything. And often when you do not want them
<br>    too. This includes, but is not limited to: proton torpedoe warhead, shuttle engines,
<br>    trucks filled with munitions, cities, puddles of water, etc. |
| --- | --- |
|  | 2) All thrown objects will explode in such a place as to cause the most
<br>    damage. Refer to rule number 1.  |
|  | 3) Being in or near a taxi is dangerous. Exception: Not for Wayne Delisle
<br>    and Michael Goines. Exception for the exception: When Michael Giones is driving. |
|  | 4) Dodge is the most important skill you can have.  |
|  | 5) You can never have enough body armor. Ask Chris Fisher, or Ed Stokes. |
|  | *5a) Other characters being carried count as appliqué armor.  * |
|  | 6) Always remember, *"It's not our fault." *You will get
<br>    to use this saying. A lot.  |
|  | 7) When Ron says, "This is sooo cool," be prepared to be
<br>    screwed.  |
|  | 8) You can always tell where the group has been. Just follow the trail of
<br>    destruction.  |
|  | 9) There are always newer and more interesting weapons out there. And many
<br>    times, they are not used the way they were intended to be used. Example: Melee weapon:
<br>    Starship?  |
|  | 10) Jedi attract trouble.  |
|  | 11) While you may never get killed, there will be plenty of times you will
<br>    wish you were dead.  |
|  | 12) No gun is ever big enough.  |
|  | 13) When Wayne says, "Look out behind you," be careful about
<br>    what's in front of you.  |
|  | 14) When Ron draws a map, combat is near.  |
|  | 15) There is no such thing as overkill. Ask Allemaine, Guts, or Cybofurr
<br>    (AKA Cybokitty, AKA Furball, AKA Ahnjai Rahmma).  |
|  | 16) Never ask Ron about the rules.  |
|  | 17) Tentacles. Ron loves tentacles.  |
|  | 18) If you ask Ron a question that begins with "Can I......", it
<br>    gives Ron free reign to screw you over when he replies with "Yeah, but..."  |
|  | 19) You know you've come up with a really way out idea when you can make
<br>    Ron pause in midsentence and look all bug-eyed.  |
|  | 20) Ron brings tons of stuff to the game, so much so, that he needs a cart
<br>    to carry it all ... and even then, he has trouble navigating it to and from his car. And
<br>    much of it he will never use in game.  |
|  | 21) Don't get too used to your comfortable seat in Ron's game. You will be
<br>    asked to leave the room often, sometimes for individual roleplaying, and often for the
<br>    times that Ron splits the group up. And there is a good chance you won't like your
<br>    situation when you get back to your seat. |
