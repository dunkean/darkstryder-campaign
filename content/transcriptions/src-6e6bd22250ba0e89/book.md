---

**STAR WARS RPG** 

**Accuracy Bonus

**"Getting more bang for you credit"

| **Result Points** | **Accuracy Bonus** |
| --- | --- |
| **0** | 0 |
| 1-3 | +1 |
| 4-6 | +2 |
| 7-8 | +1D |
| 9-11 | +1D+1 |
| 12-13 | +1D+2 |
| 14-15 | +2D |
| 16-20 | +2D+1 |
| 21+ | +1
<br>    pip every 3 points above 20 |

Results points is the difference between the difficulty and the Roll made by the
player. The Accuracy Bonus is added to the damage of the weapon.  This counts for
both Melee, Brawling and Ranged weapons.
