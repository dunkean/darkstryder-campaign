| Known Issues |
| Many page numbers missing from Sources and Data Sources. |
| Leading spaces in many Range and die code columns to avoid Excel automatically formatting into dates. |
| Armor game effects are currently lumped under Game Notes; ideally should be broken into separate columns for armor vs. Energy, vs. Physical, DEX penalties, etc. |
| Duplicates exist in database, are marked where found under the Duplicates column (hidden) |
| Some duplicates are, in fact, variant stats that should be marked as such. |
| Variant stats, such as those translated by High Admiral, are catalogued but currently not listed in database. |
| Stat inconsistencies (such as the terms for "Ion damage" or "Ionization Damage", or "+2" rather than "0D+2") are known to exist in the database. These stats are currently presented AS-IS (that is, as found in the source material, reproducing the originally-published inconsistencies). |
| Several statistics (such as Shadow Droid) could technically fall under multiple sections (eg, Droids and Starships), but are currently listed under the best-fit section. Ideally they should be included (with correct section formatting) under all applicable sections. |
| Many of the longer bits of text simply do not fit nicely into column view without making the spreadsheet unmanageably large. There's really no siolution to this :(. |
| Many Game Notes entries include inconsistent formatting in regards to in-cell paragraph separation. |
| Entry Index column includes many decimal entries. This is a known marker of initially incorrectly-formated data conversion and is working as intended for bookkeeping. |
| Many entries taken from Rancor Pit Conversions incorrectly list "Galaxy Guide 9 - Bounty Hunters" as a source (Bounty Hunters is GG10, Fragments from the Rim is GG9). These must be individually checked to see if they're really GG9 or GG10. |
| Some inconsistencies exist as to whether related Alien Species or Creatures are sorted by Species ("Ubese (True)" and "Ubese (Yrak Pootzck)"), or Subspecies ("True Ubese" and "Yrak Pootzck Ubese")). |
| Hidden Unfinished section lists stats with broken data, or known variants that have not yet been categorized. |
|  |
| Future Goals |
| Standardize stat inconsistencies (such as the afore-mentioned "Ion Damage/Ionization Damage", including many Creature ability terms), but NOT the actual die codes. UPDATING OF GAME STATISTICS IS NOT THE GOAL OF THIS ARCHIVE. |
| Include variant stats such as High Admiral's alternate conversions. |
| Include variant conversions directly from the D20 material, to be included in addition to the existing D6-substitutions-for-D20 (for completeness). |
| Include WEG and WTC publication index numbers for source materials. |
| Include column denoting the official status of statistics, and from which source they originate. |
| Include column(s) for relevant time periods to allow statistics to be sorted by the era in which they are available. |
| Include FFG material. |
| Include fan material, such as RPGGamer.org, Fallon Kell's Starship Construction System, and the Star Wars PBEM Pettycomp stats (to be marked as variant or unofficial stats). |
| Include NPC stats, both generics and unique characters. |
| Include capsules (longshot). |
| Include images (longshot). |
| List all known starship and vehicle weapons as individual entries in the Weapons category; correlate with known prices and weights where applicable. |
| Complete time taken column for specific types of equipment that have a noted time interval (either to install, or to use) |
