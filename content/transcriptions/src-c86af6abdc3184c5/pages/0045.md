As a general rule, Force powers without prerequisites have a learning difficulty of five. Increase that value by five for each prerequisite power.For example,boost senses, which has no prerequisites, has a learning difficulty of five. Cloak presence,which has one prerequisite powers (trance 5D) has a learning difficulty of 10.

In addition, if the gamemaster finds that the rapid advancement of Ta-Ree spell ability is destabilizing game play, it is possible to increase learning difficulty even more. For each die of a required power that is necessary to use a Ta-Ree spell, increase the difficulty by+1.For example, cloak presence has a base learning difficulty of five, with an additional five added for the required power trance (increasing the difficulty to 10).Finally,the required die code level for trance is 5D;add +1 to the difficulty for each die of the required power (in this case, an additional +5. Using this method, the difficulty for learning cloak presence is 15.

## TA-REE SPELLS

## AWAKEN

Required Power: Stay conscious 5D

Difficulty:Moderate for incapacitated characters; Difficult for mortally wounded characters. Modified by relationship.

Time To Use: One minute.

Effect: The target returns to consciousness. The target has the same restrictions as imposed by the stay conscious power. The Ascendant attempting to use awaken must be touching the target in order to use this power successfully. This power can counteract the effects of the TaRee spell sleep.

Required Power: Battle sense 2D

Difficulty:Moderate+opponent'swillpoweror Perception.

Time To Use: One round.
