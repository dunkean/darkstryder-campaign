# Star Wars D6 — database and reference inventory

Research: **21 October 2026**. Acquisition/import update: **22 October 2026**, CPU only. See [initial import audit](sw-d6-acquisition-merge-2026-10-22.md) and [additional acquisitions and import status](sw-d6-acquisition-followup-2026-10-22.md). English sources prioritized; French sources included where useful. Counts marked “checked” come from downloaded files, before deduplication. “Downloaded” means the specified data files, not a complete copy of the website or application.

**Yes: substantial structured material already exists.** Start with **SW-WEG-D6-Toolkit**, **swd6-character-generator**, and the **Essential Companion**. They can save considerable stat-block transcription. I did not find a single audited database combining the complete DarkStryder scenario, WEG rules, lore, and source-level evidence.

Downloads are stored **outside this repository**. See [local download receipt](../catalog/sw-d6-research.local.json) for the directory and manifests. Below, paths are relative to that directory. The acquired datasets now have adapters into the separate [unified SW database](sw-d6-unified-pipeline.md); campaign JSON and the legacy KBase are unchanged. The updated acquisition status below distinguishes downloaded corpora from sources still unavailable; it is not a claim that every inventoried website has been mirrored.

**Verified SQLite import, 22 October:** **128,507 documents**, including **33,740 newly acquired entries**; **68,904 working aggregates**, **24,502 with multiple documents**. Integrity, foreign keys, current-version hashes and preservation of all earlier evidence passed. Algorithmic document preparation marks **10,498 redundant documents** for exclusion from the later text merge; originals remain available. [Native Jev document curation](sw-d6-native-curation-2026-10-22.md) is running with the user-authorized strict **>80% redundancy** threshold. The following paragraph pass is prepared but not started. ## Retrieval and quality notes

- **35 literal JS tables converted to JSON** under `derived-json/`, without executing downloaded code. Original files are preserved. Toolkit `data_rooms.js` has a syntax error at line 1815 and was **not converted**; this concerns its station/game content.
- vehrka's five `*-template.json` files contain non-strict JSON syntax; treat them as illustrative templates, not directly loadable records. Its CSV files were preserved as supplied.
- Each downloaded dataset has a manifest with URL, retrieval time, SHA-256 and, for GitHub, pinned commit. Derived-table metadata also records the original file and line unit. Sourcebook page strings have **not** been checked against the PDFs.
- The wiki dump's checksum matches Internet Archive metadata and its XML parses successfully. It repeats page elements across revision groups: **33,370 XML page elements are not 33,370 distinct pages**. `unique-page-index.jsonl` uses page IDs; the complete history remains intact. The dump log lists five unavailable images.
- These sources overlap heavily. Preserve source IDs and distinguish **WEG originals, REUP/editorial revisions, fan conversions, lore summaries and generated content**. Imported material should remain unreviewed; existing campaign state and personal overlays stay separate. External map coordinates are not local map calibration.
- For your next step: inspect **Toolkit DarkStryder records → generator ship/droid/species tables → Essential Companion archetypes/rules**. Keep the original transcriptions for scenario structure, exact evidence and resolving conflicts.
